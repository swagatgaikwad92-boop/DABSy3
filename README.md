# Magic World assets
Derived from the artwork you supplied; nothing redrawn. `build_assets.py` cropped/cleaned transparent PNGs to WebP.
- `dabsy-body.webp` (279x251), `dabsy-eye-l/r.webp`, `dabsy-bow.webp` — the supplied body, separate eyes and bow.
- `dabsy-halo.webp` — a cool rim light derived from the body silhouette; `dabsy-flecks.webp` — stray fur flecks from the full sprite.
- `room-night.webp` — the supplied night room. **No day room was supplied**, so none exists here.
- `geometry.json` — measured placement of eyes/bow on the body. See `habitats-data.js` to add rooms/spots.
